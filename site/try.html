Talk to Voxie

Start a call

There's no public demo server yet. Run Voxie on your own machine (an NVIDIA GPU for the voice, plus your Deepgram, Groq and Sarvam keys in .env), then call it from this page.

git clone https://github.com/SomehowLiving/Voxie && cd Voxie
cp .env.example .env   # add your keys
docker compose -f compose.release.yaml up

Your browser may ask to allow this page to reach devices on your network. Allow it: the call goes from your browser straight to your Voxie, never through us.
